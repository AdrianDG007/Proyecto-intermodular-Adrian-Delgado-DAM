## 4. Presentacion del proyecto

**¿Que es el proyecto?**
He desarrollado una aplicacion de gestion para una tienda de videojuegos. La aplicacion permite gestionar el catalogo de juegos, los clientes y los pedidos de la tienda.

**¿Que problema resuelve?**
Una tienda pequeña que lleva todo en papel o en hojas de calculo puede perder mucho tiempo buscando informacion. Esta aplicacion centraliza todo en una base de datos y permite hacer consultas rapidas, añadir nuevos productos, registrar clientes y controlar los pedidos.

**¿Para quien esta pensado?**
Para el personal de una pequeña tienda de videojuegos que necesite una herramienta sencilla para gestionar su negocio sin complicaciones.

**Tecnologias utilizadas:**
- Java (programacion de la aplicacion)
- MySQL (base de datos)
- JDBC (conexion entre Java y MySQL)
- Git y GitHub (control de versiones)
- XML y XSD (exportacion del catalogo)

**¿Que he aprendido desarrollandolo?**
He aprendido a conectar una aplicacion Java con una base de datos real usando JDBC, a diseñar un modelo de datos desde cero y a organizar un proyecto con varias capas. Tambien he mejorado bastante con Git, porque he ido haciendo commits a lo largo del proyecto en lugar de subir todo al final.

## 5. Portfolio basico
