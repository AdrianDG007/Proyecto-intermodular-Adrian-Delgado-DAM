# Gestión Tienda de Videojuegos

Aplicación de consola desarrollada en Java para la gestión integral de una tienda de videojuegos.

## ¿Qué hace esta aplicación?
Permite la gestión del catálogo de videojuegos, los clientes de la tienda y los pedidos realizados, con conexión a base de datos MySQL mediante JDBC.

## Tecnologías
 - Java
 - MySQL
 - JDBC

## Módulos del proyecto
|          Módulo        |                Descripción                  |
|------------------------|---------------------------------------------|
| Bases de Datos         | Diseño E/R, modelo relacional y scripts SQL |
| Programación           | Aplicación Java con JDBC                    |
| Lenguajes de Marcas    | XML y XSD del catálogo                      |
| Entornos de Desarrollo | Control de versiones con Git/GitHub         |
| Sistemas Informáticos  | Informe del entorno de ejecución            |

## Estructura del repositorio
 - `/src`      — Código fuente Java
 - `/sql`      — Scripts de base de datos
 - `/xml`      — Ficheros XML y XSD
 - `/diagrams` — Diagrama E/R
 - `/docs`     — Documentación técnica
